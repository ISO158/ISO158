## 📌 Sobre Mim

Sou mestrando em Física na Universidade de São Paulo (IFUSP) com foco de pesquisa em **Biofísica**. Minha atuação acadêmica e técnica combina **modelagem quantitativa, análise de dados complexos, automação de instrumentos e machine learning** aplicados à física de sistemas biológicos e espectroscopia.

Atualmente estou expandindo minha atuação para a indústria, aplicando metodologias analíticas e computacionais avançadas para a resolução de problemas complexos em Ciência de Dados e Inteligência Artificial.
